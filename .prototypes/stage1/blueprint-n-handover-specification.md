End-to-End User Flow & State Machine[STATE 1: home-menu]
   │  • User melihat daftar modul Tadarruj (Modul 01 Aktif, Modul 02-04 Segera/Disabled).
   │  • User dapat mengganti bahasa (EN / ID) kapan saja via Pill Selector di Header.
   ▼ (Klik "Start ➔" pada Modul Penjumlahan Dasar)
[STATE 2: module-setup]
   │  • User mengatur 4 parameter latihan:
   │    1. Display Mode: 'interactive' (Satu per Satu) vs 'jembreng' (Semua Soal).
   │    2. Digit Specification: Preset Instan (Satuan..Campuran) atau Custom Portion (%) via Modal.
   │    3. Total Questions: 5 | 10 | 15 | 20.
   │    4. Time Limit (Timer): 'off' (Santai) | '5' | '10' | '15' menit.
   ▼ (Klik "Start Practice 🚀" -> Math Engine men-generate array QuestionItem[])
[STATE 3: practicing]
   │  • Header menampilkan tombol "← Quit" (memicu Modal Konfirmasi Batal), indikator progres, & Timer.
   │  • Mode 'interactive': Menampilkan 1 soal besar di tengah, auto-focus input, submit per soal.
   │  • Mode 'jembreng': Menampilkan daftar soal scrollable dalam wadah terukur, 1 tombol submit akhir.
   ▼ (Soal terakhir dijawab / klik Submit -> memicu Modal Konfirmasi Kirim Jawaban)
[STATE 4: result]
      • Menampilkan Skor (0-100), Rasio Akurasi, dan Rekapitulasi Jawaban (Kiri: Soal Murni, Kanan: Status/Koreksi).
      • Tombol Aksi Ganda: "📝 Setup Menu" (kembali ke module-setup) & "🏠 Main Menu" (kembali ke home-menu).

Aturan Bisnis Math Engine (Penjumlahan Non-Negatif)Batas Maksimal Hasil: Seluruh operasi penjumlahan dirancang agar hasil akhir tidak melebihi 5 digit ($99.999$).Mode Preset Instan:satuan: $1 \dots 9$ (maks hasil $18$)puluhan: $10 \dots 99$ (maks hasil $198$)ratusan: $100 \dots 999$ (maks hasil $1.998$)ribuan: $1.000 \dots 9.999$ (maks hasil $19.998$)campuran: Acak $1 \dots 9.999$Mode Kustom Porsi Persentase (%):Terdapat 11 pasangan kombinasi digit (1-1 hingga 4-4) yang dikelompokkan dalam 4 kategori (1d, 2d, 3d, 4d).Validasi Mutlak: Tombol "Simpan ✓" pada modal kustomisasi terkunci (disabled) selama total persentase kombinasi aktif tidak sama dengan $100\%$.Fitur Auto Balance %: Membagi rata nilai $100\%$ ke seluruh kombinasi yang dicentang (enabled), dengan sisa pembagian (remainder) didistribusikan $+1\%$ ke item teratas.Algoritma Weighted Random Selection: Menggunakan kumulatif probabilitas (Math.random() * 100) untuk menentukan pasangan digit tiap nomor soal sesuai bobot persentase pengguna.C. Sanitasi Input & Edge-Case HandlingStrict Numeric Input:Atribut type="number" inputMode="numeric" min="0".Blokir karakter non-bulat positif pada onKeyDown: ['e', 'E', '+', '-', '.', ','].Cegah perubahan angka tidak sengaja akibat mouse scroll pada onWheel (e.currentTarget.blur()).Normalisasi Leading Zeroes:Jawaban pengguna (misal "042") diparsing menggunakan parseInt(val, 10) menjadi angka murni 42 sebelum dicocokkan dengan correctAnswer dan disimpan ke rekap hasil.Safety Confirmation Modals:Quit Modal: Mencegah hilangnya progres latihan jika pengguna tidak sengaja menekan tombol ← Quit.Submit Modal: Mencegah pengiriman jawaban prematur pada soal terakhir (Mode Interaktif) maupun tombol submit akhir (Mode Jembreng).Rekap Hasil Anti-Redundansi:Sisi kiri baris rekap hanya menampilkan ekspresi soal murni (9 + 9 =).Sisi kanan menampilkan status eksklusif: ✓ 18 (jika benar) atau <span class="line-through">54</span> (7) (jika salah/kosong).🏗️ 5.
